# Data

The inputs of the notebooks. The libraries find this folder through `ODiSI_libs/paths.py`, so
the file names must not change.

The SEG-Y files describe one 2D line of 283 traces (12.5 m apart) sampled every 4 ms. Their
headers are anonymised: they contain no coordinates or survey information, and traces are
numbered 1–283.

| file | content | used by |
|---|---|---|
| `avo_intercept_A.sgy` | AVO intercept A (two-term fit, angles 1–31°) | ODiSI, CNN |
| `avo_gradient_B.sgy` | AVO gradient B | ODiSI, CNN |
| `live_window.sgy` | 1 inside the live window of the line, 0 outside. Its first and last live samples define the macro-layer horizons and the inversion window (`CFG["layers"]` in `odisi_inversion.py`); outputs are written on its trace headers | ODiSI, CNN |
| `wavelet.txt` | wavelet convolved with A cos χ + B sin χ to build the field EEI(χ) | ODiSI, CNN |
| `rock_physics_2x.json` | calibration of the pseudo-well rock physics on Well 2X: sand-porosity factor, AR(4) models, Vshale statistics of each facies. Written by `ODiSI_libs/calibrate_well2x.py` | ODiSI, CNN training set |

The field EEI is built from these files as 0.65 · (A cos χ + B sin χ) convolved with the
wavelet.

The CNN training set is generated by `CNN_libs/make_datamat.py` (notebook `02_CNN_4chis_seed0.ipynb`,
section 2.1).

## Not distributed (proprietary)

These files are not distributed:

* the seismic stack of the line;
* `well2x_data.mat`, the Well 2X logs, used for the calibration and Figures 2–3;
* `well9p_data.mat`, the logs of Well 9P, the blind well.

If they are placed in this folder, the well comparisons of the manuscript are produced as well.
